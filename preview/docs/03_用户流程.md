       ↓                            ↓

│ 上传文件         │←───────────│ 回到投稿 │
│ (拖拽/点击)      │            └──────────┘

└──────┬───────────┘
       ↓
┌──────────────────┐
│ 填写信息         │

└──────┬───────────┘            └──────────────┘
       │ 是
       ↓
┌──────────┐         ┌──────────────────┐
│ 保存草稿 │         │ 提交审核         │

## 7. 交互流程

### 7.1 共鸣（点赞）

```
浏览作品详情
→ 点击「共鸣」按钮
→ 判断是否登录
  ├─ 未登录 → 跳转登录页
  └─ 已登录
      → POST /artworks/:id/resonance
      → 按钮变红（on 状态）
      → 计数 +1
      → Redis INCR
      → 通知创作者（异步）
→ 再次点击
  → DELETE /artworks/:id/resonance
  → 按钮恢复
  → 计数 -1
```

### 7.2 收藏

```
浏览作品详情
→ 点击「收藏」按钮
→ 判断是否登录
  ├─ 未登录 → 跳转登录页
  └─ 已登录
      → POST /artworks/:id/collect
      → 按钮变红
      → 添加到「我的博物馆 > 我收藏的」
→ 再次点击
  → DELETE /artworks/:id/collect
  → 移除收藏
```

### 7.3 关注创作者

```
浏览创作者详情
→ 点击「+ 关注」按钮
→ POST /creators/:id/follow
→ 按钮变为「已关注」
→ 该创作者新作品时推送通知
→ 再次点击
  → DELETE /creators/:id/follow
  → 取消关注
```
