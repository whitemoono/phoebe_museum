# 01 · 产品需求文档 PRD

> **PHOEBE MUSEUM · 菲比博物馆**
> 这里收藏的全是菲比。对，全是。
> 版本：1.0 · 日期：2026-08-28

---

## 1. 产品概述

### 1.1 一句话定义

一个二次元角色「Phoebe（菲比）」的二创作品虚拟博物馆——所有作品中的角色都是同一个菲比，每件作品获得永久馆藏编号（PM-0000XX），与人类文明共存亡。

### 1.2 产品定位

| 维度 | 描述 |
|------|------|
| 产品类型 | UGC 二创社区 + 虚拟博物馆 |
| 核心价值 | 给每个菲比二创作品一个永久编号，让同人创作有「被收藏」的仪式感 |
| 调性 | 极简美术馆风格 + 冷幽默文案 + 严肃的荒诞感 |
| Slogan | "From PM-000001 to infinity. Very serious museum.*" |

### 1.3 目标用户

| 角色 | 画像 | 核心诉求 |
|------|------|----------|
| 创作者（画师/AI 创作者） | 20-35 岁，活跃于二次元社区 | 作品被收藏、获得编号、被共鸣 |
| 浏览者（菲比粉丝） | 15-30 岁，喜欢菲比角色 | 浏览/搜索/收藏菲比作品 |
| 审核员 | 社区志愿者/管理员 | 高效审核投稿，维护馆藏质量 |
| 管理员 | 项目维护者 | 管理用户/内容/世界线 |

### 1.4 核心问题

1. **仪式感缺失**：二创作品在社交平台发布后很快沉没，缺乏「被永久收藏」的仪式感
2. **角色一致性**：需要明确所有作品中的角色是「同一个菲比」，建立角色识别共识
3. **组织混乱**：同人作品缺乏系统化分类（按媒介/时代/世界线），难以检索
4. **社区参与低**：缺少让创作者持续参与的激励机制

### 2.2 详细功能描述

#### 2.2.1 首页发现

**展示模块：**
- Hero 轮播：精选 3-5 件馆藏作品，自动轮播 + 手动切换
- 最新馆藏：最近发布的 8-12 件作品，瀑布流/网格
- 世界线入口：热门世界线卡片 3-6 条
- 创作者推荐：活跃创作者 4-8 位
- 数据墙：总馆藏数、今日新增、活跃创作者、世界线数、最新PM编号
- 底部 CTA：「上交菲比」按钮

**交互要求：**
- 轮播自动播放间隔 5 秒，鼠标 hover 暂停
- 作品卡片点击进入详情页
- 所有模块滚动渐入（IntersectionObserver）

#### 2.2.2 馆藏列表

**筛选维度：**
- 媒介：插画 / AI / 漫画 / 3D / 视频 / 表情包
- 年份：2026 / 2025 / 2024 / 更早
- 世界线：下拉选择
- 标签：热门标签快选
- 排序：最新 / 最旧 / 最热 / 编号
- 搜索：PM编号 / 标题 / 创作者

**展示：**
- 瀑布流网格（4 列桌面 / 2 列移动）
- 每张卡片：缩略图 + PM编号 + 标题 + 创作者 + 媒介标签 + 年份
- 分页：20 条/页

#### 2.2.3 作品详情

**布局：** 左侧大图（16:9）+ 右侧信息面板

**信息面板内容：**
- PM 编号（印章红斜体）
- 中英双语标题
- 媒介标签（彩色 chip）
- 元数据表：创作者 / 年份 / 世界线 / 尺寸
- 创作说明
- 标签列表
- 共鸣/收藏按钮
- 创作者卡片链接
- 世界线归属链接

**交互：**
- 图片点击打开全屏灯箱
- 缩略图切换（多图作品）
- 上一篇/下一篇导航
- 相关作品推荐

#### 2.2.4 上交菲比（投稿）

**表单字段：**

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| 作品文件 | file[] | ✓ | 1-8 个，单文件 ≤ 50MB，支持 jpg/png/webp/mp4 |
| 标题 | text | ✓ | ≤ 60 字 |
| 描述 | textarea | | ≤ 500 字 |
| 创作媒介 | radio | ✓ | 6 选 1 |
| 归属世界线 | select | | 可选已有线或跳转创建新线 |
| 标签 | text | | 逗号分隔 |
| 创作者署名 | text | ✓ | 自动填充 @username |
| 创作年份 | text | ✓ | 默认当前年份 |
| 确认声明 | checkbox | ✓ | 必须勾选 |

**交互：**
- 拖拽上传 + 点击选择
- 上传预览（图片缩略图 / 视频预览）
- 可删除已上传文件
- 草稿保存功能
- 提交后跳转到「我的博物馆」待审列表

#### 2.2.5 我的博物馆

**Tab 页签：**
1. 我上交的（按状态分组：已发布/待审/已驳回/草稿）

4. 草稿箱

**统计区：** 已上交数 / 收藏数 / 世界线数 / 获共鸣数 / 关注数

## 4. 业务规则

### 4.1 PM 编号规则

- 格式：`PM-{6位数字}`，如 `PM-000001`
- 自增分配，不可回收，不可修改
- 审核通过时分配，驳回不分配
- 使用数据库行锁保证原子性

### 4.2 审核规则

- 审核标准：作品中的角色是菲比（同一个人物）即可通过
- 审核员可编辑标题/描述/标签后通过
- 驳回需填写原因，通知创作者
- 创作者可修改后重新提交

### 4.3 世界线规则

- 社区世界线可由任何登录用户创建
- 人类时代世界线由系统预设（7 个时代）
- 一个作品可归属一条世界线，或不归属（散件）
- 世界线创建者可邀请协作者

### 4.4 媒介分类

| 标识 | 名称 | 颜色 | 说明 |
