## 2. 路由组说明

| 路由组 | 目录 | 说明 |
|--------|------|------|
| `(public)` | `src/app/(public)/` | 公开页面，无需登录。URL 不含组名 |
| `(auth)` | `src/app/(auth)/` | 需登录页面，middleware 拦截 |
| `(admin)` | `src/app/(admin)/` | 后台页面，需 reviewer/admin 角色 |

> `(xxx)` 圆括号目录名是 Next.js 路由组，不影响 URL 路径。

## 3. 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 页面文件 | `page.tsx` | `app/(public)/collection/page.tsx` |
| 布局文件 | `layout.tsx` | `app/(admin)/layout.tsx` |
| API | `route.ts` | `app/api/artworks/route.ts` |
| 组件 | `PascalCase.tsx` | `ArtworkCard.tsx` |
| Hook | `useThing.ts` | `useArtworks.ts` |
| Service | `thing.service.ts` | `artwork.service.ts` |
| Validator | `thing.validator.ts` | `artwork.validator.ts` |
| 类型 | `thing.ts` | `artwork.ts` |
| 消息 | `xx.json` | `zh.json` |
| 测试 | `*.test.ts` / `*.spec.ts` | `artwork.service.test.ts` |
