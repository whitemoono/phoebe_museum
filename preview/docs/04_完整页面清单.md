## 各页面详细规格

### 1. 首页 `index.html`

| 项 | 说明 |
|----|------|
| **路由** | `/` |
| **鉴权** | 公开 |
| **布局** | 全宽，max-width: 1560px |
| **模块** | Hero 轮播 → 最新馆藏(4×3) → 世界线入口(3列) → 创作者推荐 → 数据墙 → CTA |
| **导航 active** | 首页 |
| **关键组件** | `Carousel`, `ArtworkGrid`, `TimelineCard`, `CreatorCard`, `StatWall` |
| **数据接口** | `GET /home` (聚合) |
| **特殊交互** | 轮播自动播放5s/hover暂停；数据墙数字递增动画；Logo 三语轮播 |

### 2. 馆藏 `collection.html`

| 项 | 说明 |
|----|------|
| **路由** | `/collection` |
| **鉴权** | 公开 |
| **布局** | 全宽网格 |
| **模块** | Hero → 筛选条 → 瀑布流网格 → 分页 |
| **筛选** | 媒介(6+ALL) / 年份 / 世界线 / 标签 / 排序 / 搜索 |
| **导航 active** | 馆藏 |
| **关键组件** | `FilterBar`, `ArtworkCard`, `Pagination` |
| **数据接口** | `GET /artworks` |

## 后台页面

### 15. 审核队列 `/admin/reviews`

| 项 | 说明 |
|----|------|
| **鉴权** | role >= reviewer |
| **模块** | 待审列表(表格) + 筛选 + 批量操作 |
| **数据接口** | `GET /admin/reviews/pending` |

### 16. 审核详情 `/admin/reviews/:id`

| 项 | 说明 |
|----|------|
| **鉴权** | role >= reviewer |
| **模块** | 作品大图 + 信息 + 审核操作(通过/驳回) |
| **数据接口** | `POST /admin/reviews/:artworkId/approve` / `reject` |

### 17. 用户管理 `/admin/users`

| 项 | 说明 |
|----|------|
| **鉴权** | role = admin |
| **模块** | 用户列表 + 搜索 + 封禁/解封 + 角色修改 |
| **数据接口** | `GET /admin/users` + `PUT /admin/users/:id` |

### 18. 内容管理 `/admin/artworks`

| 项 | 说明 |
|----|------|
| **鉴权** | role = admin |
| **模块** | 全部作品列表 + 搜索 + 删除/下架 |
| **数据接口** | `GET /admin/artworks` + `DELETE /admin/artworks/:id` |
