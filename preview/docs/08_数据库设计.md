# 08 · 数据库设计

> PHOEBE MUSEUM · 数据库设计文档
> 版本：1.0 · 日期：2026-08-28

---

## 1. 技术选型

| 组件 | 选型 | 用途 |
|------|------|------|
| 主数据库 | PostgreSQL 16 | 结构化数据存储 |
| 缓存/计数 | Redis 7 | 会话/计数器/排行榜/缓存 |
| 全文搜索 | PostgreSQL pg_trgm + GIN | 中文全文检索（MVP 阶段） |
| 对象存储 | 阿里云 OSS / AWS S3 | 图片/视频文件 |

## 2. ER 关系图

```
users ──────< artworks >────── timelines
  │              │                  │
  │              │                  │
  │              < artwork_media    │
  │              │                  │
  │              >──< tags          │
  │              │ (artwork_tags)  │
  │              │                  │
  │              < reviews          │
  │              │                  │
  ──< resonances (target: artwork/timeline)
  ──< collections
  ──< follows (self-ref: follower → following)

```

## 4. Redis 数据结构

| Key | 类型 | 说明 | TTL |
|-----|------|------|-----|
| `session:{sessionId}` | String | 用户会话 JWT | 7天 |
| `artwork:view:{id}` | String | 浏览量计数器 | 持久 |
| `artwork:resonance:{id}` | String | 共鸣量计数器 | 持久 |
| `hot:artworks` | ZSet | 热门作品(score=resonance+view*0.1) | 1h |
| `hot:creators` | ZSet | 热门创作者 | 1h |
| `hot:timelines` | ZSet | 热门世界线 | 1h |
| `home:latest` | List | 首页最新作品缓存 | 5min |
| `search:q:{query}` | String | 搜索结果缓存 | 5min |
| `rate:submit:{userId}` | String | 投稿频率限制 | 1h |
| `pm:lock` | String | PM编号分配分布式锁 | 10s |

## 5. 冗余计数维护策略

```sql
-- 共鸣时同步更新计数
BEGIN;
INSERT INTO resonances (user_id, target_type, target_id) VALUES ($1, 'artwork', $2);
UPDATE artworks SET resonance_count = resonance_count + 1 WHERE id = $2;
COMMIT;

-- Redis 异步同步
INCR artwork:resonance:{id}
```

定时任务每 5 分钟将 Redis 计数器回写 DB，保证最终一致性。
