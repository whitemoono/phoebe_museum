## 1. 设计哲学

### 1.1 核心理念

**「严肃的荒诞感」**——用真正博物馆的视觉语言，收藏一个荒诞的角色。

| 原则 | 说明 |
|------|------|
| 留白即奢华 | 大量负空间，内容呼吸感强，模拟美术馆墙面 |
| 衬线为骨 | 标题/编号使用 Cormorant Garamond + Noto Serif SC，传递古典博物馆气质 |
| 印章红为魂 | `#b3402a` 作为唯一强调色，模拟馆藏印章 |
| 噪点即纸面 | SVG turbulence 全屏覆盖，消除数字屏幕的塑料感 |
| 荒诞在文案 | UI 保持严肃，荒诞感由文案承载 |

### 1.2 设计参考

- 现代美术馆网页（Tate Modern, MoMa, Guggenheim）
- 独立杂志排版（Apartamento, Kinfolk）
- 日本极简设计（无印良品, 21_21 Design Sight）

## 3. 排版系统

### 3.1 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 衬线（标题） | `Cormorant Garamond` + `Noto Serif SC` | 300/400/500 weight |
| 无衬线（正文） | `Inter` + `Noto Sans SC` | 400/500 weight |
| 数字（编号） | `Cormorant Garamond` italic | PM 编号用斜体 |

```css
--serif: "Cormorant Garamond", "Noto Serif SC", serif;
--sans: Inter, "Noto Sans SC", sans-serif;
```

### 3.2 字号阶梯

| 级别 | 用途 | 桌面 | 移动 | 行高 |
|------|------|------|------|------|
| Display | Hero 大标题 | `clamp(48px, 6.4vw, 96px)` | `clamp(36px, 8vw, 48px)` | 1.0 |
| H1 | 页面标题 | `clamp(40px, 5vw, 72px)` | `clamp(32px, 6vw, 44px)` | 1.06 |
| H2 | 区块标题 | `clamp(30px, 3.6vw, 50px)` | `clamp(24px, 4vw, 32px)` | 1.08 |
| H3 | 卡片标题 | `clamp(24px, 2.4vw, 34px)` | `20px` | 1.2 |
| H4 | 小标题 | `18px` | `16px` | 1.3 |
| Body | 正文 | `13px` | `12px` | 2.0-2.2 |
| Caption | 注释 | `11px` | `10px` | 1.8 |
| Micro | 标签/编号 | `9px` | `9px` | 1.4 |

### 3.3 字间距

| 用途 | letter-spacing | 示例 |
|------|---------------|------|
| 大标题 | `-0.02em` | Hero h1 |
| 区块标题 | `-0.01em` | section h2 |
| 正文 | `0` | paragraphs |
| 小标签 | `0.14em` | nav links |
| 微标签 | `0.24em` | kickers, labels |
| 超微标签 | `0.28em-0.3em` | meta keys |

### 3.4 特殊排版

- **Kicker（引题）**: 全大写 + `0.24em` 字间距 + `#aba79a` 色，带编号前缀（如 `01 · COLLECTION`）
- **Logo 三语轮播**: `.logo small` 用 CSS animation 轮播显示中/英/日三种副标题
- **斜体强调**: Hero 标题中的关键词用 `<em>` 标记，`font-style: italic; color: var(--seal)`

## 5. 布局系统

### 5.1 网格

| 页面 | 桌面列数 | 说明 |
|------|----------|------|
| 首页轮播 | 单列 | 全宽 |
| 首页最新馆藏 | 4 列 | gap 24px |
| 馆藏瀑布流 | 4 列 | gap 24px |
| 社区世界线 | 3 列 | gap 30px |
| 创作者列表 | 4 列 | gap 24px |
| 创作者作品 | 4 列 | gap 24px |
| 相关作品 | 3 列 | gap 30px |
| 我的博物馆 | 4 列 | gap 24px |
| 作品详情 | 1.35:0.65 | 左图右信息 |
| 档案馆 | 240px:1fr | 左侧边+右表格 |
| 登录 | 1:1 | 左视觉右表单 |

### 5.2 断点

| 断点 | 宽度 | 变化 |
|------|------|------|
| Desktop | > 1100px | 完整布局 |
| Tablet | 760px-1100px | 详情页单列；网格 3→2 列 |
| Mobile | < 760px | 所有网格 2 列；导航变汉堡 |

### 5.3 响应式规则

- 1100px: 作品详情左右分栏 → 单列
- 960px: padding 增大；上下篇导航 → 纵向
- 760px: 所有 4列→2列；隐藏部分导航项；显示汉堡菜单

## 6. 组件视觉规格

### 6.1 按钮

| 类型 | 样式 | 示例 |
|------|------|------|
| `.btn.solid` | 印章红背景白字 | 主 CTA（上交菲比） |
| `.btn.ghost` | 透明背景墨色边框 | 次要操作 |
| `.submit-btn` | 导航 CTA，印章红背景 | 导航栏 |
| 链接按钮 | 底线 1px | 文本内链接 |

- padding: 桌面 `14px 28px`，移动 `12px 20px`
- font-size: `11px-12px`
- letter-spacing: `0.14em-0.2em`
- transition: `all 0.3s var(--ease)`

### 6.2 标签 Chip

```css
.chip {
  display: inline-flex;
  font-size: 9px;
  letter-spacing: 0.14em;
  padding: 4px 10px;
  border-radius: 2px;
  /* 背景色为媒介色 */
}
```

### 6.3 作品卡片

| 元素 | 规格 |
|------|------|
| 图片 | aspect-ratio: 3/4，overflow hidden |
| 图片 hover | `transform: scale(1.06)` + `filter: brightness(1.05)`，0.8s ease |
| PM编号 | 9px，`0.14em` letter-spacing，`#aba79a` |
| 标题 | Serif，15px，500 weight |
| 元数据 | 10px，`#77746a` |

### 6.4 印章

```css
.stamp {
  position: absolute;
  font-family: var(--serif);
  font-style: italic;
  color: var(--seal);
  border: 2px solid var(--seal);
  padding: 8px 14px;
  border-radius: 4px;
  transform: rotate(-8deg);
  opacity: 0.85;
}
```

### 6.5 导航栏（液态玻璃）

```css
.pm-nav {
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 100;
  transition: all 0.4s var(--ease);
}
.pm-nav.scrolled {
  background: var(--glass);
  backdrop-filter: blur(20px) saturate(1.6);
  border-bottom: 1px solid rgba(255,255,255,.5);
  box-shadow: 0 8px 32px -12px rgba(22,21,15,.12);
}
```

### 6.6 纸面噪点

```html
<svg style="position:fixed;inset:0;width:100%;height:100%;pointer-events:none;opacity:.04;z-index:9999">
  <filter id="noise"><feTurbulence type="fractalNoise" baseFrequency=".85" numOctaves="3"/></filter>
  <rect width="100%" height="100%" filter="url(#noise)"/>
</svg>
```

## 7. 图像规范

### 7.1 作品图片

| 用途 | 尺寸 | 格式 |
|------|------|------|
| 原图 | 不限 | jpg/png/webp |
| 大图（详情页） | max 2048px 宽 | webp |
| 缩略图（卡片） | 400px / 800px | webp |
| 方形缩略图 | 200×200 | webp |

### 7.2 封面图

- 世界线封面：16:9 比例
- 创作者头像：1:1 圆形
- Hero 背景：全屏 cover

### 7.3 懒加载

```html
<img loading="lazy" src="thumb.webp" data-full="full.webp">
```

## 8. 国际化视觉

| 元素 | 中/英/日 处理 |
|------|---------------|
| Logo 副标题 | CSS 动画三语轮播 |
| 导航链接 | `data-lang-zh` / `data-lang-en` / `data-lang-ja` 属性切换 |
| 页面标题 | 多语言变体同时存在 DOM 中，通过 CSS display 切换 |
| 切换按钮 | 中 / EN / 日，active 态加粗 |
| 持久化 | `localStorage('phoebe-lang')` 存储语言偏好 |
