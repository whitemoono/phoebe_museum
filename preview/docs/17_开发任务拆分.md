## 4. 关键路径

```
M1 基础设施 (1w)
  ├── 1.3 Prisma → 3.x API 开发 (后端关键路径)
  └── 1.2 pm.css → 2.x 页面开发 (前端关键路径)

M2 前端 (3w) ←── M1
  └── 2.3 作品详情 ← 2.1 首页 ← 1.6 共享组件

M3 后端 (3w) ←── M1 (与 M2 并行)
  └── 3.2 作品 API ← 1.5 认证 ← 1.3 Prisma

M4 后台 (2w) ←── M2 + M3
M5 测试 (2w) ←── M2 + M3
M6 部署 (2w) ←── M5
```

**关键路径：** M1 → M3 → M5 → M6 ≈ 8 周

## 5. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| PM 编号并发冲突 | 中 | 高 | 行锁 + 分布式锁 |
| 图片上传慢 | 中 | 中 | OSS 直传 + CDN |
| 搜索性能差 | 中 | 中 | pg_trgm GIN 索引 + Redis 缓存 |
| 三语翻译质量 | 低 | 低 | 社区贡献 + 人工校对 |
| 审核积压 | 中 | 中 | 增加审核员 + 批量审核 |
| E2E 测试 flaky | 高 | 低 | 重试 + 稳定 selector |
