# 07 · 交互设计规范

> PHOEBE MUSEUM · 交互设计规范
> 版本：1.0 · 日期：2026-08-28

---

## 1. 交互原则

| 原则 | 说明 |
|------|------|
| 即时反馈 | 所有可交互元素 hover/click 在 300ms 内给出视觉反馈 |
| 轻量动效 | 使用 `transform` 和 `opacity` 驱动动画，避免 layout reflow |
| 渐进揭示 | 滚动时内容渐入（IntersectionObserver），避免一次性加载闪烁 |
| 状态可见 | 按钮点击后状态变化必须可见（toggle 颜色/文字变化） |
| 容错友好 | 表单校验在 blur 时触发，错误信息贴近字段，不弹窗 |
| 无侵入 | 不使用 alert/confirm/prompt，用 toast/modal 替代 |

## 2. 页面级交互

### 2.1 导航栏

| 交互 | 触发 | 效果 |
|------|------|------|
| 滚动玻璃态 | `window.scrollY > 24` | 背景从透明 → `var(--glass)` + `backdrop-filter: blur(20px)` |
| 导航高亮 | 当前页面 | 对应链接添加 `.active`，颜色变 `--seal` |
| 移动端汉堡 | 点击 `☰` | 抽屉从右滑入，按钮变 `✕` |
| 抽屉关闭 | 点击抽屉外/`✕` | 抽屉滑出，按钮恢复 `☰` |
| 语言切换 | 点击 中/EN/日 | 全局切换 `data-lang` 显示，存入 `localStorage` |

### 2.2 滚动渐入

```js
// 所有 .rv 元素
threshold: 0.06
rootMargin: '0px 0px -40px 0px'
// 进入视口 → 添加 .in → opacity 0→1 + translateY 40px→0
// 动画完成后 unobserve（只触发一次）
```

### 2.3 回到顶部

| 触发 | 效果 |
|------|------|
| `scrollY > 600` | 右下角 `↑` 按钮 fade in |
| 点击 | `window.scrollTo({ top: 0, behavior: 'smooth' })` |

### 2.4 纸面噪点

- 全屏 SVG `feTurbulence` 覆盖层
- `opacity: 0.04; z-index: 9999; pointer-events: none`
- 纯装饰，不影响交互

## 3. 组件级交互

### 3.1 作品卡片

| 交互 | 效果 | 时长 |
|------|------|------|
| hover 图片 | `transform: scale(1.06)` + `filter: brightness(1.05)` | 0.8s `--ease` |
| hover 媒介标签 | 颜色加深 | 0.3s |
| click 卡片 | 跳转 `/artwork/:pmNo` | - |

### 3.2 世界线卡片

| 交互 | 效果 |
|------|------|
| hover 图片 | `transform: scale(1.05) rotate(0.6deg)` |
| hover 状态标签 | `backdrop-filter` 模糊加深 |

### 3.3 灯箱（Lightbox）

```
点击作品大图
→ body overflow: hidden
→ .lightbox 添加 .open (display: flex)
→ backdrop: rgba(22,21,15,.72) + backdrop-filter: blur(18px)
→ 图片 fade+scale in
→ ESC 或点击遮罩关闭
→ body overflow 恢复
```

### 3.4 轮播

| 交互 | 效果 |
|------|------|
| 自动播放 | 5秒切换，`opacity` 交叉淡入淡出 |
| hover | 暂停自动播放 |
| 左右箭头 | 手动切换 |
| 圆点指示 | 点击跳转到指定 slide |

### 3.5 Tab 切换

```
点击 Tab 按钮
→ 所有按钮移除 .active
→ 当前按钮添加 .active
→ 所有 panel 隐藏 (display: none)
→ 对应 panel 显示 (display: '')
→ 无动画（即时切换，保持博物馆克制感）
```

### 3.6 筛选器

| 交互 | 效果 |
|------|------|
| 点击媒介标签 | 切换 active，重新请求列表 |
| 切换下拉 | 触发筛选，列表更新 |
| 搜索输入 | debounce 300ms 后请求 |
| 列表更新 | 旧列表 fade out → 新列表 fade in (0.3s) |

### 3.7 上传区

| 交互 | 效果 |
|------|------|
| 拖拽进入 | border 变 `--seal`，背景变 `--bg-soft` |
| 拖拽离开 | 恢复默认 |
| drop 文件 | 处理文件，生成预览 |
| 点击 | 触发隐藏 `<input type=file>` |
| 文件预览 | 图片 → `<img>` / 视频 → `<video>` |
| 删除预览 | 点击 `✕` 移除 |

### 3.8 共鸣/收藏按钮

```
初始态：.fav-btn（透明底，墨色文字）
点击：
  → POST API
  → 成功 → 添加 .on（红底白字）+ 计数+1
  → 失败 → toast 提示
再次点击：
  → DELETE API
  → 成功 → 移除 .on + 计数-1
未登录点击：
  → 跳转 /login?redirect=current
```

### 3.9 表单

| 元素 | 交互 |
|------|------|
| input focus | `border-bottom-color: var(--seal)`，0.3s |
| input blur | 校验，错误 → 显示错误信息（红色，贴近字段） |
| textarea | 同 input，可拖拽调整高度 |
| select | 自定义箭头，`appearance: none` |
| checkbox | 自定义样式，`appearance: none` + 伪元素 |
| radio | 卡片式选择，选中 → border 变红 + 背景微红 |
| 提交按钮 | hover → 背景色加深 |

### 3.10 分页

| 交互 | 效果 |
|------|------|
| 点击页码 | 跳转到对应页，滚动到列表顶部 |
| 点击 ←/→ | 上一页/下一页 |
| active 页码 | 深色背景白色文字 |

## 4. 动效规范

### 4.1 动效时长

| 场景 | 时长 | 缓动 |
|------|------|------|
| hover 变色 | 0.25-0.3s | `var(--ease)` |
| hover 图片缩放 | 0.8-1.0s | `var(--ease)` |
| 滚动渐入 | 0.9s | `var(--ease)` |
| 导航玻璃态 | 0.4s | `var(--ease)` |
| 灯箱打开/关闭 | 0.3s | `var(--ease)` |
| Tab 切换 | 0s（即时） | - |
| 表单 focus | 0.3s | `var(--ease)` |

### 4.2 动效属性

**推荐**（GPU 加速）：
- `transform: scale() / translateY() / rotate()`
- `opacity`
- `filter: brightness() / blur()`

**避免**（触发 layout）：
- `width / height` 变化
- `top / left` 变化
- `margin / padding` 变化

### 4.3 Logo 三语轮播

```css
.logo small {
  position: absolute;
  opacity: 0;
  animation: logoCycle 9s infinite;
}
.logo small[data-lang-zh] { animation-delay: 0s; }
.logo small[data-lang-en] { animation-delay: 3s; }
.logo small[data-lang-ja] { animation-delay: 6s; }

@keyframes logoCycle {
  0%, 28% { opacity: 1; }
  33%, 95% { opacity: 0; }
}
```

## 5. 手势/键盘

### 5.1 键盘

| 按键 | 功能 |
|------|------|
| `ESC` | 关闭灯箱/抽屉 |
| `←` `→` | 灯箱内切换图片 / 轮播切换 |
| `Tab` | 焦点遍历（可见 focus ring） |

### 5.2 触摸

| 手势 | 功能 |
|------|------|
| 左右滑动 | 轮播切换 |
| 点击 | 触发对应元素 click |
| 长按 | 无特殊功能 |

## 6. 加载状态

| 场景 | 方案 |
|------|------|
| 列表加载 | 骨架屏（灰色占位卡片） |
| 图片加载 | `background: var(--bg-soft)` 占位 + `loading="lazy"` |
| 按钮提交 | 按钮内显示 spinner + 禁用 |
| 页面切换 | 顶部进度条（nprogress 风格） |
| 灯箱图片 | 居中 spinner |

---

## 7. 空状态

| 场景 | 设计 |
|------|------|
| 无搜索结果 | 居中文字「没找到这个菲比——也许你该上交一个？」+ 搜索建议 |
| 草稿箱空 | 居中 `✎` 图标 + 「还有 X 份草稿没交」+ 编辑按钮 |
| 我的博物馆空 | 居中文字 + 「上交第一张菲比」CTA |
| 收藏空 | 居中文字 + 「去馆藏逛逛」CTA |

---

## 8. 错误状态

| 场景 | 方案 |
|------|------|
| 网络错误 | toast: 「网络开了点小差，重试一下？」 |
| 404 页面 | 居中「这件菲比不存在——可能还没被上交。」+ 返回首页 |
| 表单校验 | 字段下方红色文字，不阻断其他字段 |
| 权限不足 | 跳转登录页，带 redirect 参数 |
| 服务器错误 | 居中「博物馆暂时闭馆了，稍后再来。」 |

## 9. 响应式交互差异

| 交互 | 桌面 | 移动 |
|------|------|------|
| 导航 | 完整链接 + 语言 + CTA | 汉堡菜单 → 抽屉 |
| 卡片网格 | 4 列 | 2 列 |
| 作品详情 | 左右分栏 | 单列纵向 |
| 筛选 | 全部展开 | 可折叠/下拉 |
| 分页 | 全部页码 | 简化（前/后/当前） |
| 搜索 | 搜索框 | 搜索图标展开 |
| 上下篇导航 | 左右并排 | 上下堆叠 |

## 10. 可访问性

| 项 | 实现 |
|----|------|
| focus ring | 不移除 `:focus-visible` outline |
| ARIA 标签 | 按钮加 `aria-label`（如汉堡菜单 `aria-label="菜单"`） |
| 语义化 | `<header><nav><main><footer><article>` |
| alt 文本 | 所有图片提供 alt |
| 键盘导航 | 所有交互可通过键盘完成 |
| 对比度 | WCAG 2.1 AA（ink/bg 对比 > 7:1） |
| reduced motion | `@media (prefers-reduced-motion: reduce)` 关闭动画 |

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
