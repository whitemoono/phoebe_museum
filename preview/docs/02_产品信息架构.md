# 02 · 产品信息架构

> PHOEBE MUSEUM · 信息架构与导航体系
> 版本：1.0 · 日期：2026-08-28

---

## 1. 顶层架构

```
菲比博物馆 PHOEBE MUSEUM
│
├─ 公开浏览（游客可访问）
│   ├─ 首页（发现入口）              /
│   ├─ 馆藏（全量瀑布流 + 筛选）     /collection
│   ├─ 时间线
│   │   ├─ 人类时间线（真实历史时代） /timeline/human
│   │   ├─ 时代详情                   /timeline/era/:slug
│   │   ├─ 社区世界线（平行世界AU）  /community
│   │   ├─ 世界线详情                 /timeline/:slug
│   │   └─ 创建世界线（需登录）      /timeline/create
│   ├─ 创作者
│   │   ├─ 创作者列表                 /creators
│   │   └─ 创作者详情                 /creator/:username
│   ├─ 档案馆（表格索引 + 高级检索） /archive
│   └─ 作品详情                       /artwork/:pmNo
│
├─ 需登录
│   ├─ 上交菲比（投稿）              /submit
│   ├─ 我的博物馆（个人中心）        /my
│   │   ├─ Tab: 我上交的
│   │   ├─ Tab: 我收藏的
│   │   ├─ Tab: 我的世界线
│   │   └─ Tab: 草稿箱
│   └─ 登录 / 注册                   /login
│
└─ 管理后台（审核员 / 管理员）
    ├─ 待审队列                       /admin/reviews
    ├─ 审核操作                       /admin/reviews/:id
    ├─ 用户管理                       /admin/users
    └─ 内容管理                       /admin/artworks
```

## 3. 信息层级

### 3.1 首页信息层级

```
首页
├─ L1: Hero（品牌 + 大标题 + 副标题）
│   └─ 轮播作品
├─ L1: 最新馆藏（网格 4×3）
│   └─ 作品卡片 → 作品详情
├─ L1: 世界线入口
│   └─ 世界线卡片 → 世界线详情
├─ L1: 创作者推荐
│   └─ 创作者卡片 → 创作者详情
├─ L1: 数据墙
│   └─ 统计数字（装饰性 + 信息性）
└─ L1: CTA
    └─ 「上交菲比」按钮 → 投稿页
```

### 3.2 馆藏列表信息层级

```
馆藏
├─ L1: 页面标题 + 描述
├─ L1: 筛选条
│   ├─ 媒介标签（ALL / 插画 / AI / 漫画 / 3D / 视频 / 表情包）
│   ├─ 年份下拉
│   ├─ 世界线下拉
│   ├─ 排序下拉
│   └─ 搜索框
├─ L1: 瀑布流网格
│   └─ 作品卡片
│       ├─ 缩略图
│       ├─ PM编号
│       ├─ 标题
│       ├─ 媒介标签
│       └─ 创作者 + 年份 → 详情页
└─ L1: 分页
```

### 3.3 作品详情信息层级

```
作品详情
├─ L1: 面包屑（馆藏 > 世界线 > 作品）
├─ L1: 主区域（左图右信息）
│   ├─ 左: 大图区
│   │   ├─ 主图（点击灯箱）
│   │   └─ 缩略图导航
│   └─ 右: 信息面板
│       ├─ PM编号（印章红）
│       ├─ 标题（中英双语）
│       ├─ 媒介标签
│       ├─ 元数据表
│       │   ├─ 创作者 → 创作者详情
│       │   ├─ 年份
│       │   ├─ 世界线 → 世界线详情
│       │   └─ 尺寸/文件信息
│       ├─ 创作说明
│       ├─ 标签
│       └─ 共鸣/收藏按钮
├─ L1: 创作者信息卡
├─ L1: 相关作品（3列网格）
└─ L1: 上一篇/下一篇导航
```

### 3.4 我的博物馆信息层级

```
我的博物馆
├─ L1: Hero（头像 + 用户名 + 入馆编号）
├─ L1: 统计栏（5 个统计数字）
├─ L1: Tab 切换
│   ├─ Tab 1: 我上交的
│   │   └─ 作品网格（带状态标签）
│   ├─ Tab 2: 我收藏的
│   │   └─ 作品网格
│   ├─ Tab 3: 我的世界线
│   │   └─ 世界线列表行
│   └─ Tab 4: 草稿箱
│       └─ 空状态/草稿列表
```

## 4. 内容分类体系

### 4.1 按媒介分类

```
媒介
├─ 插画 ILLUSTRATION（手绘/数绘）
├─ AI CREATION（AI 生成/辅助）
├─ 漫画 COMIC（条漫/分镜）
├─ 3D / MODEL（3D 建模/渲染）
├─ 视频 VIDEO（动画/短片）
└─ 表情包 STICKER（表情/贴纸）
```

### 4.2 按时间线分类

```
时间线
├─ 人类时间线（系统预设，7 个时代）
│   ├─ 史前菲比 PREHISTORIC
│   ├─ 古代菲比 ANCIENT
│   ├─ 中世纪菲比 MEDIEVAL
│   ├─ 文艺复兴菲比 RENAISSANCE
│   ├─ 近代菲比 MODERN
│   ├─ 当代菲比 CONTEMPORARY
│   └─ 未来菲比 FUTURE
│
└─ 社区世界线（用户创建，无限）
    ├─ CYBER PHOEBE（赛博菲比）
    ├─ PIRATE PHOEBE（海盗菲比）
    ├─ STORE PHOEBE（便利店菲比）
    ├─ MECHA PHOEBE（机甲菲比）
    ├─ GHOST SHIP PHOEBE（幽灵船菲比）
    └─ ...（持续增长）
```

### 4.3 按状态分类（作品）

```
作品状态
├─ DRAFT（草稿，仅创作者可见）
├─ PENDING（待审核，审核员可见）
├─ PUBLISHED（已发布，公开可见）
└─ REJECTED（已驳回，创作者可见）
```

### 4.4 标签体系

- 自由标签，用户投稿时输入
- 系统聚合统计使用次数
- 热门标签展示在档案馆侧边栏
- 无预设标签分类（完全 UGC 驱动）

## 5. URL 路由设计

| 路由 | 页面 | 参数 | SSR/SSG |
|------|------|------|---------|
| `/` | 银首页 | - | SSR（动态首页数据） |
| `/collection` | 馆藏列表 | `?medium=&year=&timeline=&tag=&sort=&page=` | SSR |
| `/artwork/:pmNo` | 作品详情 | `pmNo` (PM-0000XX) | SSG（已发布预渲染） |
| `/timeline/human` | 人类时间线 | - | SSG（预设数据） |
| `/timeline/era/:slug` | 时代详情 | `slug` | SSG |
| `/community` | 社区世界线 | `?sort=` | SSR |
| `/timeline/create` | 创建世界线 | - | CSR（需登录） |
| `/timeline/:slug` | 世界线详情 | `slug` | SSR |
| `/creators` | 创作者列表 | `?sort=` | SSR |
| `/creator/:username` | 创作者详情 | `username` | SSR |
| `/archive` | 档案馆 | `?q=&medium=&year=&timeline=&sort=&page=` | SSR |
| `/submit` | 上交菲比 | - | CSR（需登录） |
| `/my` | 我的博物馆 | `?tab=` | CSR（需登录） |
| `/login` | 登录 | `?redirect=` | CSR |
