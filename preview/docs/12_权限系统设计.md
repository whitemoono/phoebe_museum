## 1. 角色体系

### 1.1 角色定义

| 角色 | 标识 | 层级 | 说明 |
|------|------|------|------|
| 游客 | `guest` | 0 | 未登录用户，仅可浏览公开内容 |
| 创作者 | `creator` | 1 | 注册用户，可投稿/创建世界线/共鸣/收藏/关注 |
| 审核员 | `reviewer` | 2 | 可审核投稿，分配PM编号 |
| 管理员 | `admin` | 3 | 最高权限，可管理用户/内容/世界线 |

### 1.2 角色继承

```
admin (3)
  └─ reviewer (2)
       └─ creator (1)
            └─ guest (0)
```

高层级自动包含低层级所有权限。

### 3.2 前端路由守卫

```ts
// middleware.ts (Next.js)
export async function middleware(req: NextRequest) {
  const { pathname } = req.nextUrl;

  // 需登录的路由
  const authRequired = ['/my', '/submit', '/timeline/create'];
  if (authRequired.some(p => pathname.startsWith(p))) {
    const token = req.cookies.get('token')?.value;
    if (!token) {
      return NextResponse.redirect(new URL(`/login?redirect=${pathname}`, req.url));
    }
  }

  // 需审核员的路由
  const adminRequired = ['/admin'];
  if (adminRequired.some(p => pathname.startsWith(p))) {
    const token = req.cookies.get('token')?.value;
    if (!token) return redirectToLogin(req);
    const payload = jwt.verify(token);
    if (!['reviewer', 'admin'].includes(payload.role)) {
      return NextResponse.redirect(new URL('/?error=forbidden', req.url));
    }
  }
}
```

### 3.3 后端 API 守卫

```ts
// 需登录
export async function withAuth(handler) {
  return async (req) => {
    const user = await getSessionUser(req);
    if (!user) return errorResponse(40101, '请先登录');
    return handler(req, user);
  };
}

// 需审核员+
export async function withReviewer(handler) {
  return async (req) => {
    const user = await getSessionUser(req);
    if (!user) return errorResponse(40101, '请先登录');
    if (!['reviewer', 'admin'].includes(user.role)) {
      return errorResponse(40301, '权限不足');
    }
    return handler(req, user);
  };
}

// 需管理员
export async function withAdmin(handler) {
  return async (req) => {
    const user = await getSessionUser(req);
    if (!user) return errorResponse(40101, '请先登录');
    if (user.role !== 'admin') {
      return errorResponse(40301, '权限不足');
    }
    return handler(req, user);
  };
}
```

### 3.4 前端组件级权限

```tsx
// components/PermissionGate.tsx
export function PermissionGate({ require, children, fallback = null }) {
  const { user } = useAuthStore();
  const userLevel = ROLE_LEVELS[user?.role || 'guest'];
  const requiredLevel = ROLE_LEVELS[require];
  if (userLevel < requiredLevel) return <>{fallback}</>;
  return <>{children}</>;
}

// 使用
<PermissionGate require="creator">
  <SubmitButton />
</PermissionGate>

<PermissionGate require="reviewer" fallback={null}>
  <AdminNav />
</PermissionGate>
```

### 3.5 数据级权限

```ts
// 编辑作品：仅本人 + 非已发布
async function editArtwork(userId: number, artworkId: number, data) {
  const artwork = await prisma.artwork.findUnique({ where: { id: artworkId } });
  if (!artwork) throw new ApiError(40401, '作品不存在');
  if (artwork.creatorId !== userId) throw new ApiError(40301, '只能编辑自己的作品');
  if (artwork.status === 'published') throw new ApiError(40302, '已发布作品不可编辑');
  return prisma.artwork.update({ where: { id: artworkId }, data });
}

// 删除作品：本人(非已发布) 或 管理员
async function deleteArtwork(userId: number, artworkId: number) {
  const user = await getUser(userId);
  const artwork = await prisma.artwork.findUnique({ where: { id: artworkId } });
  if (!artwork) throw new ApiError(40401, '作品不存在');
  if (user.role !== 'admin' && artwork.creatorId !== userId) {
    throw new ApiError(40301, '无权删除他人作品');
  }
  if (artwork.status === 'published' && user.role !== 'admin') {
    throw new ApiError(40302, '已发布作品不可删除');
  }
  return prisma.artwork.delete({ where: { id: artworkId } });
}
```

## 4. 角色管理

### 4.1 角色变更规则

| 操作 | 谁可执行 | 规则 |
|------|----------|------|
| 升为审核员 | 管理员 | 通过后台手动设置 |
| 升为管理员 | 管理员 | 仅现有管理员可执行 |
| 降级 | 管理员 | 降级后立即失去对应权限 |
| 封禁用户 | 管理员 | `status=banned`，JWT 立即失效 |

### 4.2 审核员选拔

- 由管理员手动指定
- 需要有一定投稿数量（≥ 10 件已发布）
- 需要有一定的社区信誉（无违规记录）
- 可随时撤回

## 5. 安全策略

| 策略 | 实现 |
|------|------|
| 密码存储 | bcrypt hash（salt rounds=12） |
| JWT 过期 | 7天，可 remember me 延长至 30 天 |
| CSRF | SameSite cookie + token header |
| XSS | React 默认转义 + CSP header |
| 速率限制 | 登录 5/min, 投稿 5/h, 共鸣 30/min |
| 会话管理 | Redis 存储 session ID，封禁即失效 |
| 文件上传 | 白名单 MIME + 大小限制 + OSS 隔离 |
