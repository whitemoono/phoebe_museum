# 13 · 后台管理系统

> PHOEBE MUSEUM · 后台管理系统设计
> 版本：1.0 · 日期：2026-08-28

---

## 1. 概述

后台管理系统供审核员和管理员使用，包括：
- **审核队列**：审核投稿作品，分配PM编号
- **用户管理**：查看/封禁/解封用户，修改角色
- **内容管理**：查看/下架/删除作品和世界线
- **数据看板**：统计概览

---

## 3. 审核队列

### 3.1 列表页 `/admin/reviews`

**布局：** 表格

| 列 | 说明 |
|----|------|
| 缩略图 | 80×80 |
| 提交时间 | 日期 |
| 标题 | 作品标题 |
| 创作者 | @username |
| 媒介 | chip 标签 |
| 状态 | pending |
| 操作 | [审核 →] |

**筛选：** 媒介 / 创作者 / 提交时间范围
**排序：** 默认按提交时间升序（先提交先审核）

### 3.2 审核详情页 `/admin/reviews/:id`

**布局：** 左图右信息（类似前台作品详情）

**左侧：**
- 作品大图（点击可全屏查看）
- 多图时显示缩略图切换

**右侧信息面板：**
- 提交时间
- 标题（可编辑）
- 创作者信息
- 描述（可编辑）
- 媒介
- 标签（可编辑/增删）
- 归属世界线（可修改）

**操作区：**

| 按钮 | 动作 |
|------|------|
| ✅ 通过 | 分配PM编号 → status=published → 进入馆藏 → 通知创作者 |
| ❌ 驳回 | 弹出输入框 → 填写驳回原因 → status=rejected → 通知创作者 |
| ✏ 编辑 | 修改标题/描述/标签后通过 |
| ← 返回 | 回到队列 |

**通过流程：**
```
点击「通过」
→ 分配 PM 编号（allocatePmNo）
→ status = published, published_at = NOW()
→ 创建 review 记录 (action=approve)
→ 触发缩略图生成队列
→ 发送通知给创作者
→ 回到队列
```

**驳回流程：**
```
点击「驳回」
→ 弹出 modal：输入驳回原因
→ status = rejected, rejection_reason = 原因
→ 创建 review 记录 (action=reject)
→ 发送通知给创作者
→ 回到队列
```

## 4. 用户管理

### 4.1 列表页 `/admin/users`

**表格列：**

| 列 | 说明 |
|----|------|
| 用户ID | |
| @username | 链接到创作者主页 |
| 昵称 | display_name |
| 邮箱 | |
| 角色 | creator/reviewer/admin |
| 状态 | active/banned |
| 注册时间 | |
| 投稿数 | |
| 操作 | [编辑] |

**搜索：** 用户名/邮箱/ID
**筛选：** 角色 / 状态

### 4.2 用户编辑

**可修改字段：**
- 角色（creator → reviewer → admin）
- 状态（active ↔ banned）

**封禁效果：**
- JWT 立即失效（Redis 删除 session）
- 已发布作品保留
- 新投稿被拒
- 显示「该账号已被封禁」

**表格列：**

| 列 | 说明 |
|----|------|
| PM编号 | |

## 7. UI 设计

后台使用前台同一设计系统（`pm.css`），保持视觉一致性：

- 使用同一字体（Cormorant Garamond + Inter）
- 使用同一色板（ink/line/seal）
- 导航简化为后台专用
- 表格风格同档案馆
- 按钮使用 `.btn.solid` / `.btn.ghost`

**差异：**
- 后台无三语切换（仅中文）
- 后台无纸面噪点覆盖
- 后台导航为左侧边栏 + 顶部
- 后台无液态玻璃效果
